# Microsoft 365 / Outlook SMTP Configuration Guide

This guide details how to configure custom SMTP delivery in Supabase for **`@sheshi.ai`** using Microsoft 365 / Outlook.

---

## ⚡ Verified Connection Test Results
- **Host**: `smtp.office365.com`
- **Port**: `587`
- **Status**: ✅ **ACTIVE & RESPONSIVE** (`Microsoft ESMTP MAIL Service ready`)

---

## 🛠️ Step-by-Step Supabase Dashboard Setup

1. Open your **[Supabase Auth Settings](https://supabase.com/dashboard/project/ikkyziyugrnkolqnrxfo/settings/auth)**.
2. Scroll down to the **SMTP Settings** section.
3. Toggle **Enable Custom SMTP** to **ON**.
4. Fill in the following fields:

| Field | Configuration Value |
|---|---|
| **Sender Email** | `goutham.ra@sheshi.ai` |
| **Sender Name** | `Sheshi Vault` |
| **Host** | `smtp.office365.com` |
| **Port** | `587` |
| **Minimum TLS Version** | `TLSv1.2` / `STARTTLS` |
| **Username** | `goutham.ra@sheshi.ai` |
| **Password** | *Your Outlook Password or Microsoft App Password* |

5. Click **Save** at the bottom of the page.

---

## 🔑 Microsoft 365 / Outlook Requirements

### 1. Enable Authenticated SMTP in Microsoft 365 Admin Center
1. Go to **[admin.microsoft.com](https://admin.microsoft.com)**.
2. Go to **Users > Active Users** and select `goutham.ra@sheshi.ai`.
3. Select the **Mail** tab.
4. Under **Email apps**, click **Manage email apps**.
5. Ensure **Authenticated SMTP** is **checked**.
6. Click **Save changes**.

### 2. If 2FA / Multi-Factor Authentication is Enabled
If your `@sheshi.ai` account uses 2-Step Verification:
1. Go to **[myaccount.microsoft.com](https://myaccount.microsoft.com)**.
2. Navigate to **Security info > Add method > App password**.
3. Copy the 16-character App Password generated by Microsoft.
4. Use this App Password as your SMTP password in Supabase.

---

## 🧪 Testing Email Delivery
Once saved in Supabase Dashboard:
1. Go to your web app at `http://localhost:5173`.
2. Click **Forgot Password**.
3. Type `goutham.ra@sheshi.ai` and click **Send Password Reset Email**.
4. Check your Outlook inbox (`goutham.ra@sheshi.ai`) for the reset email!
